## 🛠️ Jak uruchomić?
1. **Python:** Wymagany Python w wersji 3.x. Wystarczy pobrać dany plik `.py` i uruchomić go w swoim IDE lub terminalu. 
2. **Access & Excel:** Pliki `.accdb` oraz `.xlsx`/`.xlsm` są gotowe do otwarcia w pakiecie MS Office. 
Warto pamiętać o pobraniu plików źródłowych (`.txt` z danymi maturalnymi) i umieszczeniu ich w tym samym folderze, jeśli skrypt tego wymaga.
